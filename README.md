# 🤖 Asynchronous Telegram Echo Bot

A lightweight and stable Telegram chat-bot built with Python using the modern **aiogram 3** framework. 

## 🛠️ Key Features
* **Echo Mode:** Instantly replies to users by mirroring their text messages.
* **Admin Notifications:** Automatically forwards incoming user messages to the administrator's private chat for real-time monitoring.
* **Asynchronous Architecture:** Powered by `asyncio` to handle multiple user requests simultaneously without performance drops.

## 💻 Tech Stack
* Python 3.11+
* aiogram 3.x
* asyncio

## 🚀 How to Run Locally
1. Clone this repository or download the `bot.py` file.
2. Install the required dependency:  
   `pip install aiogram`
3. Insert your unique Telegram API token from @BotFather into the `TOKEN` variable.
4. Run the script using the following command:  
   `python bot.py`
